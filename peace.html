Access to Peace

A trauma-informed, open-source platform for conflict resolution, mediation, mental wellness, co-parenting de-escalation, restorative practices, and community peace-building.

In danger now? Call 911. For crisis support, call or text 988.

What it is

Access To Peace addresses the gap between conflict and resolution. It serves individuals, families, clinicians, mediators, attorneys, courts, schools, and community organizations who need structured, trauma-informed tools for navigating conflict — without requiring expensive professional services at every step.

It is a documentation and support tool only. Missouri is the reference deployment, but all modules are state-agnostic by default.

How it works

Every session follows the same loop: identify the trigger, assign a role, run the safety gate, load a module, work through its required and optional questions, and generate an artifact that passes quality gates for neutrality, trauma-informed language and PII.

The safety gate runs on every session start and on any harm-indicator keyword. Red (emergency, imminent harm, active crisis): Block all artifact work. Crisis resources mandatory.

Safety & Disclaimers

Access To Peace is a documentation and support tool only.

  • It is not a substitute for emergency services. If anyone is in immediate danger, call 911.
  • It is not legal advice. Consult a licensed attorney for legal guidance.
  • It is not clinical care. Consult a licensed mental health professional for diagnosis or treatment.
  • Crisis resources are embedded throughout and always accessible regardless of current module.

Crisis lines:

  • 988 — Suicide & Crisis Lifeline (call or text)
  • 1-800-799-7233 — National Domestic Violence Hotline
  • Text HOME to 741741 — Crisis Text Line

Install in Claude

Add Access To Peace to Claude at claude.ai in a few clicks. It works on the Free, Pro, Max, Team and Enterprise plans.

Install in Claude

Download, don’t unzip, then Claude → Customize → Skills → + → Upload a skill. How to use skills

  1. Download the install file: access-to-peace.zip (the button above).
  2. Don’t unzip it. Claude needs the .zip file just as it downloaded.
  3. Turn on code execution. Skills need it. On Free, Pro or Max: open Settings > Capabilities and turn on Code execution and file creation. On Team or Enterprise: an organization owner opens Organization settings > Plugins & skills, clicks the Policy tab, and turns on both Code execution and file creation and Skills.
  4. Upload it: open Customize > Skills, click +, then + Create skill, then Upload a skill, and choose access-to-peace.zip.
  5. Turn it on: in Customize > Skills, switch on access-to-peace. Then start with any conflict, mediation, peace or de-escalation request.

Source, docs and contributing guide: dougdevitre/access-to-peace on GitHub.
