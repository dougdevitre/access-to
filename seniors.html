Access for Seniors

AI-powered platform for senior connection, loneliness mitigation, and aging-services navigation. It helps senior living communities, home health agencies, health systems, and AAAs detect isolation early, keep families connected, and route older adults to the programs and benefits they’ve earned.

In danger now? Call 911. For crisis support, call or text 988. For Spanish crisis support: 988, press 2, or text AYUDA to 988.

What it is

Access for Seniors is a Claude skill: a product, engineering, compliance, and go-to-market assistant for Access For Seniors, a HIPAA-aligned, multi-tenant SaaS platform for senior connection, engagement scoring, caregiver alerts, family outreach, and aging-services navigation (OAA, Medicare, Medicaid, AAA).

It guides the work of building and running that platform: feature design, data models and APIs, engagement scoring, aging-services navigation, infrastructure and deployment, and marketing.

How it works

The skill reads one short entry file and loads reference files only when a topic comes up: the 28 module specs, the conversation engine, engagement scoring, aging services, security, data models and more.

For an aging-services question it matches the need to a program (OAA Title III-B, III-C, III-D, III-E, VII; Medicare Parts A–D; Medicaid LTSS; AAA; Meals on Wheels), gives eligibility criteria, how to apply and the referral handoff, and cites primary sources (acl.gov, medicare.gov, cms.gov, state AAA).

What It Does

AI Companion

Memory-aware conversations with seniors via text and voice (Anthropic Claude).

Engagement Signals

Multi-signal detection of reduced social connection. Not diagnoses: connection signals.

Caregiver Dashboard

Real-time alerts, resident profiles, shift notes, and reporting.

Family Outreach

AI-generated, warm, personalized messages that encourage family connection.

Aging-Services Navigation

Match needs to OAA, Medicare, Medicaid, AAA, Meals on Wheels, caregiver respite.

Security & Compliance

HIPAA-aligned defaults (encryption, audit logging, tenant isolation, BAAs). Consent-first: AI features require explicit resident/guardian consent. Elder abuse mandatory reporting support (state-dependent).

Install in Claude

Add Access for Seniors to Claude at claude.ai in a few clicks. It works on the Free, Pro, Max, Team and Enterprise plans.

Install in Claude

Download, don’t unzip, then Claude → Customize → Skills → + → Upload a skill. How to use skills

  1. Download the install file: access-for-seniors.zip (the button above).
  2. Don’t unzip it. Claude needs the .zip file just as it downloaded.
  3. Turn on code execution. Skills need it. On Free, Pro or Max: open Settings > Capabilities and turn on Code execution and file creation. On Team or Enterprise: an organization owner opens Organization settings > Plugins & skills, clicks the Policy tab, and turns on both Code execution and file creation and Skills.
  4. Upload it: open Customize > Skills, click +, then + Create skill, then Upload a skill, and choose access-for-seniors.zip.
  5. Turn it on: in Customize > Skills, switch on access-for-seniors. Claude will now use it for any Access for Seniors question.

Engagement scores are connection signals, not clinical diagnoses. Source, docs and contributing guide: dougdevitre/access-for-seniors on GitHub.
